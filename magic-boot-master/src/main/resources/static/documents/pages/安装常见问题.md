# 安装常见问题
                
本文档收集了安装过程中可能遇到的常见问题及其解决方案。

## 问题1: 安装脚本权限不足

**问题描述**:
执行安装脚本时提示"权限被拒绝"。

**解决方案**:
给安装脚本添加执行权限：
\`\`\`bash
chmod +x install.sh
\`\`\`

## 问题2: 依赖包安装失败

**问题描述**:
安装过程中依赖包下载失败。

**解决方案**:
1. 检查网络连接
2. 尝试更换包管理器镜像源
3. 手动下载依赖包

## 问题3: 端口被占用

**问题描述**:
启动服务时提示端口已被占用。

**解决方案**:
1. 查找占用端口的进程并停止
   \`\`\`bash
   lsof -i :8080
   \`\`\`
2. 修改配置文件使用其他端口

## 问题4: 数据库连接失败

**问题描述**:
应用无法连接到数据库。

**解决方案**:
1. 检查数据库服务是否运行
2. 验证数据库连接参数
3. 检查防火墙设置
